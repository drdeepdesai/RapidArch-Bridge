# RapidArch Dentafab Bridge

Installer downloads and release notes for the **RapidArch Dentafab Bridge** — a small, free Windows helper that lets the RapidArch editor send prints to Dentafab printers on your clinic's WiFi.

## Download

**[⬇ Download the latest installer](https://github.com/drdeepdesai/RapidArch-Bridge/releases/latest/download/RapidArch-Bridge-Windows.zip)** (Windows 10/11)

Or see full instructions at **[rapidarch.com/dentafab-bridge](https://rapidarch.com/dentafab-bridge)**.

## Install

1. Download and extract the ZIP on the computer that's on the same WiFi as your printer.
2. Double-click **RapidArch Bridge Setup** and click **Install**. (If Windows shows "Windows protected your PC", click **More info → Run anyway** — the installer isn't code-signed yet.)
3. Look for the green **RA** badge in the system tray, near the clock. Green means the bridge is running and the editor will find your printer automatically.

Installs per-user — no admin rights, no Windows service, nothing system-wide. It starts by itself at every login.

## Reading the tray icon

- 🟢 **Green "RA"** — bridge running, WiFi printing works.
- 🔴 **Red "RA"** — bridge stopped; right-click the icon and choose **Start bridge**.
- **No icon** — use the **RapidArch Bridge** shortcut on the Desktop or in the Start menu (safe to click any time).

## Uninstall

Run **RapidArch Bridge Setup** again and click **Uninstall**.
